# 声线朗读台 · 朗读作业提交与同伴互评

在「声线练习室」基础上扩展的纯前端教学应用：教师布置朗读句子作业并设截止时刻，学生在截止前提交录音，跨组同伴互评打分与评语，不及格退回重录并保留全部版本。

## 运行

```bash
npm install
npm run dev      # 开发
npm run build    # 类型检查 + 生产构建
```

## 功能与规则

- **作业与截止**：教师布置句子作业、设定截止时刻与及格线；逾期通道关闭，首次录音、重录、撤回一律不接收。
- **唯一有效稿**：每名学生每句只保留一条有效录音。重录时旧稿先标记为「已撤回」再另存新版本；旧稿（撤回/退回）始终可查。
- **退回重录**：评审分数低于及格线，当前版本置为「已退回」，学生复录生成新版本；若此时已过截止，则永久挂起。
- **互评配对**：两人一组，一名学生只能属于一组；同组不得互评，不能自评。
- **一份录音只接一位评审人**：认领即占用（草稿也算），其他人无法再认领；评审人可放弃草稿释放录音，已提交评审不可撤回。
- **受阻清单**：所有「想做做不成」的情形集中列出，逐条给出**学生、句子、录音版本、命中规则与说明**，可按场景/类型筛选；学生端只看与自己相关的。
- **刷新一致**：作业数据、提交、配对、版本、评审与可调演示时钟均持久化在 `localStorage`，刷新后状态一致。

## 代码结构（数据 / 规则 / 页面分离）

```
src/
├── data/            # 作业数据层
│   ├── types.ts     # 领域模型与 RuleError
│   ├── seed.ts      # 种子数据（学生、配对、作业、版本、评审）
│   └── store.ts     # localStorage 持久化与写入入口（全部经 rules 校验）
├── rules/           # 规则层（纯函数，不依赖 React / 页面）
│   ├── common.ts       # 查询、配对关系、时间格式
│   ├── assignments.ts  # 布置作业校验
│   ├── submissions.ts  # 截止、唯一有效稿、撤回/重录
│   ├── pairs.ts        # 两人一组配对规则
│   ├── reviews.ts      # 认领、放弃草稿、打分退回
│   └── blockers.ts     # 受阻枚举（学生/句子/版本/规则）
├── components/      # 通用组件（模拟录音器、波形、版本回放）
├── pages/           # 页面层
│   ├── StudentPage.tsx  # 我的录音 / 同伴互评 / 受阻提示
│   └── TeacherPage.tsx  # 作业与提交矩阵 / 配对 / 受阻总表
└── __tests__/       # 规则层单元测试（tsc 编译后用 node 运行）
```

录音为**纯前端模拟**（计时器 + 伪波形，不调用麦克风），便于在无权限环境演示完整流程。侧边栏可切换教师/学生身份、调整系统时钟以演示截止时刻。
