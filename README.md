# 朗读互评台（Reading Homework · Peer Review）

由「声线练习室」扩展而来的朗读作业提交与同伴互评台。纯前端 React + Vite，无需后端：所有作业数据与操作记录写入 `localStorage`，**刷新后作业、提交、配对与版本保持一致**。

## 规则（全部由规则层强制执行，受阻即留痕）

1. 教师布置句子作业并设定**截止时刻**；逾期不再接收提交或撤回。
2. 每名学生每句只保留**一条有效录音**；重录前必须先撤回旧稿（若旧稿已被评审人认领则锁定不可撤回）。
3. 互评**两人一组**，同组之间不得互评；评审人也不能评审本人的录音。
4. 一份录音在评审池中**只接受一位评审人**：认领即独占，评审期间录音锁定；评审人可解除尚未完成的认领。
5. 评审给出分数与评语；**分数低于作业及格线即退回重录**，旧版本另存留档、仍可回放，新版本号递增。
6. 每一次被拦截的操作都会写入「受阻记录」，列出学生、句子、录音版本与命中的规则。

## 分层

- **数据层** `src/lab/types.ts`、`src/lab/seed.ts`、`src/lab/store.tsx`：实体模型、示例数据、持久化与操作执行。
- **规则层** `src/lab/pairs.ts`（配对规则）、`src/lab/policy.ts`（提交 / 撤回 / 认领 / 评审闸门）：纯函数，不依赖 React 与页面。
- **页面层** `src/components/*`：教师台、学生录音台、同伴评审台、受阻记录页。

## 使用

```bash
npm install
npm run dev      # 本地开发
npm run build    # 类型检查 + 构建
```

左侧可切换「学生 / 教师」身份，并分别选择扮演的学生与评审人，便于体验跨组评审、逾期拦截与退回重录等规则。
